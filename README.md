# BharatSpeak – AI English Communication Tutor 🇮🇳

BharatSpeak is an AI-powered English communication tutor designed for Indian
learners who understand basic English but struggle with spoken communication.

## Problem
Many learners lack confidence and a safe environment to practice spoken English,
especially for interviews and workplace communication.

## Solution
BharatSpeak uses an AI tutor to simulate real-life conversations, provide polite
grammar corrections, and explain mistakes using simple English and Hinglish.

## Key Features
- Role-play based English conversation
- Interview and workplace scenarios
- Grammar correction with explanations
- Hinglish support for better understanding
- Confidence-focused feedback

## Tech Stack
- Frontend: Streamlit
- Backend: Python
- AI: LLM (OpenAI / Gemini / Llama)

## Hackathon
This project is built as a prototype for the AI Bharat Hackathon.
